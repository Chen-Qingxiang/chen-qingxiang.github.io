# Spacetime Trails / 时空行迹

一个将人物移动、历史事件与时间轴放在同一界面中的纯静态网页原型。

## V1

- 地图显示人物事件地点与行迹；
- 已走路线、当前移动段、未来路线分别显示；
- 时间轴可拖动，可播放/暂停并调整速度；
- 地图节点、时间轴节点和事件说明双向联动；
- 自动跟随人物位置，也可关闭跟随后自由查看地图；
- 人物数据与界面分离，默认示例为 `data/lubu.json`；
- 可从浏览器临时载入符合相同结构的本地 JSON 文件。

## 数据结构

最小事件对象：

```json
{
  "year": 194,
  "dateLabel": "194 年",
  "title": "兖州反曹",
  "place": "濮阳",
  "lat": 35.761,
  "lng": 115.029,
  "summary": "事件说明",
  "tags": ["战争"],
  "source": "来源或不确定性说明"
}
```

V1 将事件地点之间以直线连接，仅表达“先后到过这些区域”，不表示实际道路或精确行军路线。

## 技术

纯 HTML/CSS/JavaScript + Leaflet 1.9.4 + OpenStreetMap 底图，无构建步骤，可直接由 GitHub Pages 托管。
