山川有来源

山海图 · Terrain Atlas 的数据、使用边界与第三方署名。发布基线：2026-09-06。

这幅地图表示什么

这是现代地形、海底深度和现代地理参照的探索工具。垂直高度可以夸张，城市和边界的水平位置保持不变。色标和探针使用未夸张的米值。它不提供历史疆域时间轴，也不把现代地貌解释为某一历史时期的地貌。

应用的代码和界面独立编写，交互灵感来自 GPlates Topography，不是 GPlates 官方产品，也不使用其服务器、品牌素材或应用源码。

地形与海底

Terrain Tiles · AWS Open Data，由 Mapzen / Tilezen 汇集的开放高程瓦片，包含 ETOPO1、GMTED2010、SRTM 与多个地区的高程资料。Terrain Tiles was accessed on 2026-09-06 from the Registry of Open Data on AWS.

本应用按视角读取 Terrarium PNG，在浏览器中解码、重采样、合成坡度明暗与配色，并在 Cesium 中生成 65×65 网格。最高读取层级为 z12；赤道附近该级别的几何采样间隔约 153 m，这不是全球源数据精度。采用一致的像素起点采样约定，共享瓦片边缘，可能相对源像元中心有半像元偏移。

数据覆盖约 85.05°S–85.05°N，极帽没有真实高程。海底与各地区陆地的数据年代、分辨率和垂直基准不一致，读数仅为近似值。未进行统一大地水准面改正；合成阴影不代表某一时刻的日照。海水不遮挡海底，调节倍率也会放大海沟深度。

文件与网络

GeoJSON 在当前浏览器解析，不上传到服务器。第一版的导入图层仅在本次页面会话中保留，刷新后需重新导入；分享链接仅携带相机和显示设置。软件会向 jsDelivr / unpkg 请求地图引擎，向 AWS 请求视野中的高程瓦片。基础矢量数据来自本站。没有 API 密钥、账号或统计追踪。

这是研究观察工具，不能用于精密测绘、工程或航海决策。详细用法、部署方式与已知限制见 项目 README。
