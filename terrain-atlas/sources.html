Where the terrain comes from

Data sources, limits of use and third-party attribution for Terrain Atlas · 山海图. V1.1 updated 2026-09-07.

What this map represents

This is an exploration tool for modern topography, bathymetry and modern geographic reference layers. Vertical elevation can be exaggerated while cities and boundaries retain their horizontal positions. The legend and terrain probe report unexaggerated metres. The app does not provide a historical-boundary timeline and does not treat modern terrain as the terrain of a particular historical period.

The application code and interface were written independently. Interaction was inspired by GPlates Topography; this is not an official GPlates product and it does not use GPlates servers, branding assets or application source code.

The default Global Relief colour scheme is based on the NOAA/NCEI ETOPO1 global-relief colour scheme. It is used only as a visual elevation ramp: Terrain Atlas still reads elevation from Terrain Tiles / Mapzen / AWS, so the palette name does not imply ETOPO1-only or SRTM15_PLUS terrain data. The colour stops are encoded independently in this project.

Terrain and seafloor

Terrain Tiles · AWS Open Data, the open elevation-tile collection assembled by Mapzen / Tilezen, combines sources including ETOPO1, GMTED2010, SRTM and several regional elevation datasets. Terrain Tiles was accessed on 2026-09-06 from the Registry of Open Data on AWS.

The app loads Terrarium PNG tiles for the current view, decodes and resamples them in the browser, applies elevation colours and optional relief shading, then generates 65×65 meshes in Cesium. The highest requested level is z12; near the equator the geometric sample spacing at that level is about 153 m. This is not the native resolution of every source dataset. A consistent pixel-origin convention is used across shared tile edges and may introduce a half-pixel offset relative to source pixel centres.

Elevation coverage is approximately 85.05°S–85.05°N; there is no real elevation data in the polar caps. Bathymetry and regional land datasets differ in date, resolution and vertical datum, so readings are approximate. No unified geoid correction is applied. Synthetic relief shading does not represent illumination at a particular time. Seawater is not rendered over the seafloor, and vertical exaggeration also magnifies trenches.

Cities, boundaries, rivers and landforms

Made with Natural Earth. The dataset version is pinned to v5.1.2, which is public domain and may be modified and redistributed.

The 1:10m and 1:50m labels mean cartographic scales of 1:10 million and 1:50 million, not metre-level resolution. The reference layers are intended for overview use and do not include every town, river or local administrative boundary. Country boundaries do not include complete coastlines or maritime claims. Boundaries and naming follow the upstream data and do not express a project position on disputed areas.

The original river attribute table contains Chinese names. The GeoJSON export of the same version omits those attributes, so this project reads the pinned Shapefile directly and stores SHA-256 hashes for the SHP, DBF, PRJ and CPG files. Landform labels are restricted to large mountains, plateaus, basins, plains, deserts and selected valleys and deltas; label anchors are not precise geometric centres.

The data manifest records source URLs, source-file SHA-256 values, output shards and simplification tolerances.

Files and network access

GeoJSON is parsed locally in the current browser and is not uploaded. Imported layers remain only for the current page session and must be imported again after a refresh. Shared links contain only camera and display settings. The app requests the map engine from jsDelivr / unpkg, terrain tiles from AWS, and base vector data from this site. There are no API keys, accounts or analytics trackers.

This is a research and observation tool, not a product for precise surveying, engineering or navigation. See the project README for deployment details and known limitations.
