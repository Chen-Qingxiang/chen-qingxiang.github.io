# Qingxiang Chen — personal site

Source for [chen-qingxiang.github.io](https://chen-qingxiang.github.io/).

The homepage is a lightweight, responsive static page. Project essays under `_posts/` continue
to be built by GitHub Pages and remain available at their existing URLs.

## Local preview

The homepage itself can be opened directly or served with any static file server:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000/`.
